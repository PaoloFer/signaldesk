# Roadmap

The current product focuses on bounded, explainable sample analysis.

## Near Term

- Harden owner bootstrap and public registration.
- Move public-preview rate limiting from process memory to Redis.
- Apply report scope consistently across NLP, search, overlap, and ADV endpoints.
- Add channel and niche detail views with evidence drill-down.
- Improve backup verification and PostgreSQL migration tests in CI.

## Explore

- Persist exploration runs, seeds, provenance, and API cost.
- Represent discovery as waves from user-provided seeds.
- Attach evidence depth and coverage to nodes and edges.
- Produce a compact Niche Depth report with explicit stop conditions.

## Compose

- Build a reusable market index and channel representations.
- Retrieve affine, aspirational, and frontier candidates.
- Add include/exclude feedback and transparent reranking.
- Materialize accepted recommendations as monitored niches.

These are roadmap items and are not described as current product capabilities.
